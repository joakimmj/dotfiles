# bat

## Config

Set theme
``` tangle:~/.config/bat/config
--theme="TwoDark"
```

Show line numbers, Git modifications and file header (but no grid)
``` tangle:~/.config/bat/config
--style="numbers,changes,header"
```

Always show colors
``` tangle:~/.config/bat/config
--color=always
```

Always show decorations
``` tangle:~/.config/bat/config
--decorations=always
```
